# Data card

The corpus consists of Strudel task–solution pairs. Each item has a natural-language task,
one of eight task dimensions, a reference function and one reference solution. The pairs were
generated by a large language model from 158 hand-verified Strudel documentation examples, under
rules restricting the sample and synthesiser vocabulary, and each solution was verified to
execute in the Strudel engine. Dissertation Chapter 3 describes construction and cleaning.

## Format

JSON Lines, one chat-format item per line:

```json
{"messages": [
  {"role": "system",    "content": "You are a Strudel coding assistant. ..."},
  {"role": "user",      "content": "Dimension: <dimension>\nTask: <task>\nReference function: <F>"},
  {"role": "assistant", "content": "<reference Strudel code>"}
]}
```

## `cleaned/` — the corpus used for all fine-tuning experiments

| File | Items | Role |
|---|---|---|
| `train_set_finetuned.jsonl` | 906 | LoRA training set |
| `test_set_150_finetuned.jsonl` | 150 | **Validation** set: per-epoch checkpoint selection during training (the file name is historical) |
| `test_set_150_new.jsonl` | 150 | **Test** set: frozen; all reported results after cleaning |
| `train_only.jsonl` | 1,056 | Pool from which few-shot demonstrations are drawn |

Training, validation and test sets are pairwise disjoint (by task text), 906 + 150 + 150 = 1,206 items.
No test task appears in the demonstration pool.

The demonstration pool and the union of training and validation sets contain the same 1,056 reference
solutions; 35 of them carry a differently worded task description in the pool.

## `original/` — the corpus as first constructed

| File | Items | Role |
|---|---|---|
| `train_set_unified.jsonl` | 1,376 | Demonstration pool of the baseline survey |
| `test_set_150.jsonl` | 150 | Test set of the baseline survey |

These files are included only to reproduce the baseline survey, which predates cleaning. They
contain the problems that cleaning removed:
- 255 pool items and 31 test items contain a chord pattern without `voicing()`; these execute without
  error and produce no sound.
- 37 test tasks also appear in the pool.

Do not use them for new experiments.

## Known limitations

- Every solution was generated by one language model, not written by people.
- Each task has a single reference solution; a different correct program scores as disagreeing with it.
- Informal listening covered roughly a tenth of the corpus; no ratings were recorded.
